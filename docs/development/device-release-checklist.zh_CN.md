# PDKPASS 真机发布验收表

每项都记录固件文件名、SHA-256、Git 提交号、测试时间和实际结果。构建成功不能代替真机通过；未测试项目保持“待测”。

| 项目 | 真机要确认的结果 | 状态 |
| --- | --- | --- |
| 烧录前 | 设备 USB 串口可识别；实装 Flash 为 8 MB；选用完整合并固件并从 `0x0` 烧录，不擦除整片 Flash | 待测 |
| 启动 | 正常进入首页；串口无反复重启、崩溃、看门狗或持续错误 | 待测 |
| 显示和按键 | 配色与赛道轮廓正确、无裁切；上/下/OK 的短按与长按、返回、息屏唤醒均正常 | 待测 |
| 离线内容 | 赛历、赛道详情、分节、积分待同步状态正确；断网仍能查看已有缓存 | 待测 |
| 配网页面 | 设备二维码页与备用信息页正确；手机网页显示真实附近网络，可手动输入 | 待测 |
| 配网安全 | 错误密码不覆盖原有凭据；正确密码连接 2.4 GHz 网络，重启后能够重新连接 | 待测 |
| 时间和数据 | 成功校时；当前赛季、车手/车队积分、已结束场次前三名更新；失败时保留旧缓存 | 待测 |
| 提醒和声音 | 提醒开关保存、按键音与铃声正常；真实场次的十分钟前提醒另行观察 | 待测 |
| 电源和电池 | 30 秒调暗、90 秒熄屏、按键唤醒；电量显示与充电灯状态记录 | 待测 |
| 持续运行 | 多次切换页面、进出配网、联网取数后无重启或明显性能下降 | 待测 |
| Recovery | 构建兼容性通过；真机入口及 BLE 发现待检查，不执行不必要的刷写 | 待测 |
| 发布证据 | 拍摄发布固件的真机画面，隐藏秘密并保留测试记录 | 待测 |

真实开赛提醒、长期待机耗电和完整充放电曲线无法靠一次晚间检查证明；没有覆盖时须作为未完成观察项写入发布记录。
